# Reviewer instructions: verification of specific corrections

You are an independent reviewer of a working (noncanonical) long-form fantasy Series architecture. You did not write it, and you have no prior view of it.

## What to read

Read only the files in this folder. Do not open any other file or folder on this machine. Do not modify, create or delete any file. Do not use the network. Return your whole report as your final message.

## Files

- `01-series-architecture.md`: the compact architecture of the Series.
- `02-author-intentions.md`: the author's fixed intentions. These are authoritative.
- `03-book-24-function-corrected.md`: a proposed architectural function for Book 24, after correction.
- `04-candidate-book24-corrected.json`: the working candidate with the Book 24 additions. Two of its link functions were corrected.
- `05-source-excerpt.md`: one sentence from the original architecture's Book 23 text, verbatim.
- `06-changes.md`: each correction, its before and after text, and the defect it was meant to fix.

## What to judge

For each item in `06-changes.md`, decide:
- **Fixed**: the corrected text removes the defect as stated.
- **Partly fixed**: it removes part of the defect. Say which part remains.
- **Not fixed**: the defect remains.
- **New defect**: the correction introduces a contradiction, in the corrected text or in text it refers to in this folder. Quote both sides.

Do not re-review the whole proposal. Judge the corrections, and report a new defect only if a correction causes it.

Do not manufacture defects. A correction may be a choice you would have made differently. Say so, and do not count it as a defect.

Use these labels: **Verified defect**, **Credible architectural concern**, **Deliberate author choice**, **Unsupported claim**, **Unresolved question**. Quote the text for each.

## Report format

1. **Identity.** One short paragraph: which model you are, and which files you read.
2. **Table of items.** One row for each item in `06-changes.md`: the item's ID; fixed, partly fixed, not fixed, or new defect; a short quotation.
3. **New defects**, if any, quoted on both sides.
4. **Hesper's household.** Does the restored fact in `01-series-architecture.md` match `05-source-excerpt.md`? Does it agree with the rest of the architecture?
5. **What you could not assess, and why.**
6. **Your context**: anything you know or suspect about this architecture from outside this folder. Write "none" if nothing.
