# Experiment 1 — Story Design Pack Effect

This is a preregistered, baseline-only product-value experiment. It compares
the exact V1 story-design workflow without a pack (control) with the same
workflow supplied the built-in `superhero` pack, version `0.1.0` (treatment).

The experiment directory is research infrastructure. It does not modify
`src/auteur`, does not import the future-roadmap prototype, and does not write
story canon. Mechanical harness output is not product-value evidence.

Current status: preregistered; real generation is blocked unless an approved
real model runtime is explicitly available to the runner. No synthetic model
results may be substituted.

Read, in order:

1. `protocol.md` — frozen design and claim ceiling.
2. `cases.json` — frozen case manifest.
3. `rubric.md` — frozen evaluator rubric.
4. `generation-config.json` — frozen generation contract.
5. `run_experiment.py` — mechanical qualification and runtime gate.
