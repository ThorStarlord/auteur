# Auteur V1.0 Closure Program

This directory defines the bounded program that closes the existing Auteur architecture into a supportable `1.0.0` product contract. It is not an architecture-expansion roadmap.

## Governing objective

> Stop when every capability explicitly promised by the V1 Product Contract has a complete authority-safe path, supported persistence/freshness semantics, beginner-operable entry where required, and release evidence on the supported runtime matrix.

Anything outside the V1 Product Contract remains post-v1 even when it appears in historical audits, research, issues, or the product-evolution roadmap.

## Documents

- `v1-product-contract.md` — exact supported product surface, claim ceiling, and non-goals.
- `v1-closure-plan.md` — ordered implementation/qualification work packages and stop conditions.
- `v1-authority-artifact-matrix.md` — v1 authority, revision, dependency, freshness, and failure-atomicity contract by artifact family.
- `v1-qualification-matrix.md` — evidence required before `1.0.0` can be called release-ready.

## Program invariants

1. Close existing architecture before adding breadth.
2. Advice, projections, recommendations, and model output do not become narrative authority implicitly.
3. No v1 package may add a sixth canonical scope or a second acceptance system.
4. A failed authority-bearing action leaves prior accepted state intact.
5. V1 claims are limited to reproducible evidence from the exact frozen release candidate.
6. Deferred work does not become v1 scope merely because the repository can express it.

## Explicitly frozen during this program

Unless a V1 contract item cannot be completed without one of these capabilities, do not start: generalized Episode 2+ progression, universal causal/relationship ontology, automatic extraction, generic graph database, 50/100+ Book scale architecture, adaptive writer-skill state, cloud/collaboration, generic workflow engines, or speculative Story Design Pack expansion.
