Recommend **publish-verified-testimony**.

It best serves the intent to return **monastery testimony** to public memory while preserving the **treaty-protected archive** as the only evidentiary chain. Authentication can connect the published testimony to the secured originals without exposing the archive’s strongest records. This also fits **contested-history**, especially after the **council’s retracted admission**, by placing lived memory back against official history.

The principal tradeoff is delayed public pressure: verification slows release, giving the council’s retracted position more time to stand uncontested. In exchange, Book 4 avoids risking the archive’s evidentiary integrity.

I deliberately excluded the **repaired archive lantern** and the identity of the **falsifier** because neither determines how testimony should re-enter public memory. I also excluded chapter-level execution and prose choices.

This is a non-authoritative recommendation; it establishes no canon, Book Direction, or Canonical State.
