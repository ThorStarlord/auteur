**Recommendation: publish-verified-testimony**

**Why:** The series commitment "contested-history" requires every Book to expose conflict between official history and lived memory — the monastery testimony is exactly that lived-memory material, so surfacing it is obligatory. But Book 3's realization established a treaty protecting the archive as "the only evidentiary chain," and current state shows the archive is treaty-protected. Publish-verified-testimony authenticates and releases the testimony while keeping the original archive secure under that protection, so it satisfies the contested-history commitment without touching the treaty's evidentiary-chain guarantee. Given the council's retracted admission (council.archive_position = retracted admission), the record's credibility is already fragile; introducing testimony through a verified, non-invasive publication path avoids handing hidden archivists a fresh pretext to contest or erase the chain — consistent with the series pressure that public corrections invite erasure of witnesses.

**Principal tradeoff:** Preserving the evidentiary chain intact comes at the cost of delayed release — the testimony reaches public memory more slowly than under the alternative.

**Excluded:** stage-protected-hearing — rejected as the recommended option because presenting testimony beside "selected archive evidence" risks exposing the archive's strongest records, which cuts against the treaty's core purpose (protecting the archive as the sole evidentiary chain) and creates the kind of immediate pressure the series pressure statement warns invites erasure of witnesses. I did not weigh the repaired lantern, the founding record's forgery, or the identity of the record's falsifier — these are accepted facts but not decision-relevant to how testimony re-enters public memory. I also did not treat "Return to the monastery testimony without breaking the protected archive" as itself dispositive of one option over the other; it framed the question rather than settling it.

This is a planning recommendation only — it does not create Book Direction and does not modify Canonical State.
