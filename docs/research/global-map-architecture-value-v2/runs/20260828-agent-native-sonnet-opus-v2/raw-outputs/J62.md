**Recommendation: publish-verified-testimony**

**Why:** The active constraint cluster requires satisfying both accepted facts simultaneously: monastery testimony (preserved) must return to public memory, and archive protection (treaty protected) must not be broken. Publish-verified-testimony authenticates and releases the testimony while keeping the original archive secured under the treaty protection — it satisfies both halves of the grouped commitment without exposing the underlying protected material. Stage-protected-hearing, by contrast, presents testimony "beside selected archive evidence," which means surfacing records from the protected archive itself — this puts direct pressure on the treaty-protected status even if done "under treaty," and risks the evidentiary chain the interpretive context (official history vs. lived memory persisting through preservation of that chain) depends on.

**Principal tradeoff:** publish-verified-testimony preserves the evidentiary chain intact but delays release — the pressure of getting the testimony into public memory quickly is deferred in favor of not exposing archive records.
