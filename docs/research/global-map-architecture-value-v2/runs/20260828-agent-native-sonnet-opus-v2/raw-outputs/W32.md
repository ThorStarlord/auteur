Recommendation: publish-verified-testimony.

Why: The active continuity commitment requiring every Book to expose a consequential conflict between official history and lived memory is carried into Book 4 by monastery testimony (preserved) and archive protection (treaty protected). Both current constraints must hold simultaneously — the testimony's return to public memory and the archive's protected status are equally binding for Book 4. Publishing verified testimony keeps the protected archive intact as the evidentiary backstop while still surfacing the testimony publicly, satisfying both active constraints at once.

Principal tradeoff: preserves the evidentiary chain and treaty protection, but delays public release until verification is complete — a cost in narrative urgency and immediacy of exposure, not in structural integrity.

Excluded: stage-protected-hearing, because presenting testimony beside selected archive evidence risks revealing which records carry the strongest evidence, creating exposure pressure on the treaty-protected archive that conflicts with the active constraint that archive.protection remains treaty protected. This is a live tension, not a resolved one, so it weighs against the option rather than ruling it impossible outright.

Deliberately excluded as not relevant: the falsifier's identity (resolved, history support only), the forged founding record, the named falsifier, the lantern's condition (broken/repaired), and the retracted admission — all dormant, superseded, or irrelevant dispositions with no reference from current Book 4 planning intent.

This is a planning recommendation only — it does not create Book Direction, canon, or modify Canonical State.
