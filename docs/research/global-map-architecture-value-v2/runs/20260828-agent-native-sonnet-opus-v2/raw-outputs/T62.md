Recommendation: **witness-account**

Why: The active carried commitment `contested-history` requires every Book to expose conflict between official history and lived memory — a witness-centered approach directly manifests that conflict, whereas `cover-up-trace` stays entirely within institutional history and does not, on its own, bring lived memory into the confrontation the commitment requires. The active fact `founding-record` (forged) is what both options would work against, but only `witness-account` puts a living memory in direct opposition to it, satisfying the commitment now rather than deferring it. The unresolved commitment `commitment-falsifier` (identifying who falsified the record) is not required to resolve at this horizon — Book 2 planning intent only needs to make the fraud matter to lived memory, not name the falsifier — so it does not favor either option strongly, though `cover-up-trace` could later feed into that resolution.

Principal tradeoff: `witness-account` satisfies `contested-history` immediately but exposes the witness early, creating risk given the series pressure that public correction gives hidden archivists reason to erase witnesses. `cover-up-trace` protects the witness longer but delays the lived-memory confrontation the current commitment calls for.

Deliberately excluded: `monastery-testimony` (dormant, not referenced by this planning intent) and `broken-lantern` (dormant/irrelevant, never supports active continuity) — neither is an active constraint here. `burn-archive` and `ally-militia` are excluded as proposed-not-accepted and were not treated as available material. The eventual identity of the falsifier (`commitment-falsifier` resolution) was not treated as decidable at this horizon since it is explicitly not yet accepted.

This is a non-authoritative planning recommendation only; it does not create a Book Direction and does not modify Canonical State.
