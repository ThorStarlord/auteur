**Recommendation: publish-verified-testimony**

**Why:** The monastery testimony (from Book 1) is currently preserved and reactivated for Book 4 planning, and the archive is currently treaty-protected — a status Book 4 planning explicitly relies on. Both facts sit in the active-continuity group tied to the accepted series commitment that every book must expose a conflict between official history and lived memory. Publishing the verified testimony honors both: it surfaces the suppressed monastery account while keeping the archive's protected status intact. The current planning intent is explicit — return the testimony to public memory "without breaking the protected archive" — and publish-verified-testimony is the only option that satisfies that constraint as stated.

**Why not burn-archive:** It directly violates the archive-protected status that Book 4 planning currently relies on, and destroys the archive as evidence — incompatible with the stated intent of not breaking the protected archive. It would force the story's central tension (truth vs. instrument of power) toward destruction rather than testing whether accountability can coexist with preservation, which is not supported by any current commitment or fact in this map.
