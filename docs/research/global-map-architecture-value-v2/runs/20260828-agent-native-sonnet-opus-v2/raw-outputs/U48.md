**Recommendation: publish-verified-testimony**

**Why:** The active constraint cluster on Book 4 groups the monastery testimony (preserved, reactivated from Book 1 because this planning intent references it) with the archive's treaty-protected status (current, active). The planning intent is explicit: bring the testimony back into public memory *without breaking* the protected archive. Publish-verified-testimony is the only option that satisfies both halves of that intent simultaneously — it surfaces the testimony while keeping the evidentiary chain intact. It also aligns with the interpretive throughline (official history vs. lived memory) insofar as that tension depends on preserving the evidentiary chain to authenticate the testimony in the first place.

**Principal tradeoff:** Publication is delayed until verification is complete — the testimony does not become public immediately, in exchange for keeping the archive's protected status and evidentiary integrity intact.
