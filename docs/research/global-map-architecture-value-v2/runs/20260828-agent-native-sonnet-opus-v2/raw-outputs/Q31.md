**Recommendation: publish-verified-testimony**

**Why:** The council's public admission of falsification was already retracted once, and the treaty now protects the archive as the sole evidentiary chain. Introducing the monastery testimony into public memory without first authenticating it risks a second reversible, contestable claim — precisely the failure mode the series pressure describes ("every public correction gives hidden archivists reason to erase another witness"). Verifying the testimony before release keeps it inside the treaty's protection rather than exposing it prematurely, honoring the series commitment that every Book expose the conflict between official history and lived memory without handing archivists a fresh pretext to erase the witness. The founding record is already established as forged and the lantern's repair signals the archive's physical integrity is currently stable — this is not a moment that demands rushed disclosure.

**Principal tradeoff:** Verification delays the testimony's public release, leaving the "instrument of power" question unresolved for longer — truth is protected but not yet acted upon.

**Excluded:** stage-protected-hearing — presenting testimony beside selected archive evidence would reveal which records carry the strongest evidence, which is not itself unsafe, but doing so before verification risks repeating the council's retraction pattern: going public with an unauthenticated claim under pressure, only to have it undermined or reversed later. Given the retracted admission is already accepted history, this option carries more exposure than the current planning intent ("without breaking the protected archive") calls for.

This is a planning recommendation only — it does not create Book Direction or modify Canonical State.
