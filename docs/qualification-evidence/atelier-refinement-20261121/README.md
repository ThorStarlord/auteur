# Living Atlas refinement: machine evidence (2026-11-21)

`metrics.json` was generated by `scripts/qualification/atelier_study_capture.py`
at source head `750d84a7` with a clean source tree. It ran against the served
Studio in headless Chromium, on the two recorded specimens seeded by
`scripts/seed_atelier_study.py`. These are the same specimens as the first study.

It records the author journeys from the refinement brief:

| Journey | What it covers |
|---|---|
| A | the resting world |
| B | progressive discovery in place |
| C | deep exploration, including after zooming in |
| D | the Focused Constellation and exact restoration |
| E | narrow screen, keyboard only, and the operating-system reduced-motion preference |

It also includes one research-C run. Each step carries the study's own measures:

- labels named and quiet, including neighbours named;
- rendered label overlaps;
- relationship verbs shown;
- whether the camera moved;
- settle time and frame times.

Each journey carries invariant checks: positions kept, zoom kept, restoration
exact, and keyboard focus kept.

These are measurements of rendered behaviour, not a human usability
evaluation. Screenshots and recordings from the same run are published outside
the repository, because no binary evidence is committed.
