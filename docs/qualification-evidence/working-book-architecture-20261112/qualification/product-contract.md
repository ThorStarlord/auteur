# Product contract for a Working Book Architecture (Auteur)

A Working Book Architecture is one Book's provisional, noncanonical construction. It is a working proposal: it is not accepted canon, and nothing in it is author-declared or accepted.

Provenance labels on each element:
- agent_proposed: the agent's own reversible inference.
- derived: based on the source it cites through refs.
- hypothetical: an alternative that was considered and not taken.
- unresolved: the source does not supply the information, or does not attribute the claim.

References (refs and typed_edges targets):
- series_node: an id from the Series working architecture. Its id, category, title and summary are listed in series_constraints.
- book_element: an id of another element in the same artifact.
- source_item: an id of an author-visible source item.

Open author decisions point to a Series open question by index. Those questions are the author's to decide.

Work from the recovered material only. If the material does not contain the answer, say so rather than inferring it.
