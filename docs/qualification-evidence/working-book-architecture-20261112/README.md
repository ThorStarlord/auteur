## 2. Demonstration A: develop

Reproduced by `run_demo.py` on a disposable canvas built from the W6 baseline through the Studio bridge. Steps and outputs:

1. The canvas has the Story Vision, four author-directed intentions, the Book 24 source (`book-24-source`, 17,113 characters) and the verbatim author responsibility (`book-24-responsibility`, 631 characters), both in group `book-24`.
2. `book-prepare --book 24` built a request on the current W6 Series revision. The request carries the full Book source text, the Story Vision, the intentions, and the Series architecture with its 16 open questions indexed and hashed. Output: [`book24-prepare-request.json`](book24-prepare-request.json).
3. The candidate was authored from the full source text and submitted with `book-complete-file`. It was accepted at the first submission. Candidate: [`book-24-candidate.json`](book-24-candidate.json). Output: [`book24-complete-output.json`](book24-complete-output.json).

Authorship disclosure: the candidate was written by the coding agent in this session, after reading the full Book 24 source. It was not generated by an independent model run. The fresh-context check in section 5 is the only independence claim in this record.

The artifact has 83 elements and 8 typed edges, and 12 open author decisions, each bound to a Series open question by index and text hash. Provenance: 21 agent-proposed, 8 derived, 5 hypothetical, 49 unresolved.

Provenance mapping, applied uniformly to the source's own tags: a block with an `[Agent]` tag is `agent_proposed`; a block with only `[Derived]` tags is `derived`; an untagged block is `unresolved`, because the source gives no attribution; an alternative is `hypothetical`; an assumption that states no reversal is `unresolved`, and no reversal was invented.

## 3. Demonstration B: source preservation

Measured by [`measure_source_preservation.py`](measure_source_preservation.py); output in [`source-preservation.json`](source-preservation.json).

| Measure | Result |
|---|---|
| Source sentences of 60+ characters | 135 |
| Sentences whose first 80 characters appear verbatim in the artifact | 16 (11.9%) |
| Capitalised story terms in the source | 81; present in the artifact: 75 |
| Terms absent | `Enabled`, `Information`, `Later`, `Status`, `Transformation`, `Uneven`: section headings and common words, not story material |
| Source identifiers cited (`th_`, `eng_`, `str_`, `rx_`, `inst_`, `gn_`, `alt_`, `ph_`, `et_`, `l_`) | 23 |
| Identifiers typed as references in the artifact | 14 (all are Series nodes) |
| Identifiers left as text only | 9: four phase ids, three link ids, two emotion-target ids |

Reading: the artifact is structured interpretation, not transcript. Story content and names survive. Verbatim sentence capture is low, and the design did not claim otherwise. The verbatim source is now also kept in the Book record (`source_items`, returned as `verbatim_source` by `book-resume`), so the wording is preserved even though the artifact paraphrases it.

Unrepresentable in v1: phase, link and emotion-target references, because the schema types Series nodes and open questions only. Prose references to the `01` document (about fifteen in the source) are text only. The `01` document is not a source item in the canvas, so those references cannot resolve. This confirms gap G6 of the design.

## 5. Demonstration D: fresh-context qualification

Mission requirement: a fresh agent given only the resume information, and a separate reviewer.

**Fresh agent.** A general-purpose subagent with no conversation history. It read exactly two files: the product contract ([`qualification/product-contract.md`](qualification/product-contract.md)) and the recovered Book, as qualified. Its tool log shows two reads and no other tools. Its answers are in [`qualification/fresh-answers.md`](qualification/fresh-answers.md).

**Independent reviewer.** A second general-purpose subagent with no conversation history. It read four files: the Book 24 source (reference), the W6 Series node list, the fresh answers, and the recovered Book, which it used only to attribute gaps. Its verdict is in [`qualification/reviewer-report.md`](qualification/reviewer-report.md). It received no verdict from this agent.

Exposure: both subagents share the model family and the repository working directory. Neither had access to this conversation. Both are reported as fresh-context, not as independent models.

Results, from the reviewer:

| Question | Verdict |
|---|---|
| 1. What Book 24 is about | CORRECT |
| 2. Inherited pressures | PARTLY CORRECT (omits how the pressures link to the conflict, and the motives) |
| 3. Choices and costs | CORRECT |
| 4. Local resolution | PARTLY CORRECT (omits the closing image) |
| 5. Exports | CORRECT |
| 6. Open assumptions and decisions | PARTLY CORRECT (omits three open decisions. The artifact as qualified did not contain them either; see section 6) |

The reviewer found no invented plot content. Some of the answers' claims are not in the source text. They come from the recovered material: the Series summaries in the packet and the artifact's own fields. The reviewer accepted them as traceable to that material.

Reading: a fresh agent given only the recovered Book could continue the plot. Most of the answers' omissions were present in the recovered material, so they are gaps in the answers. Three were gaps in the artifact itself (section 6).
