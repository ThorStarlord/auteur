# Atelier visual study — machine evidence (2026-11-20)

`metrics.json` was generated by `scripts/qualification/atelier_study_capture.py`
against the served Studio (headless Chromium) on canvases seeded by
`scripts/seed_atelier_study.py` from two recorded, schema-validated Architecture
candidates. It records, per specimen, treatment and viewport, the study's own
settle measures, composition measures and the position drift after returning to
the atlas.

These are measurements of rendered behaviour, not a human usability evaluation.
Screenshots and recordings from the same run are published outside the
repository (no binary evidence is committed). Interpretation:
`docs/design/2026-11-20-living-narrative-atelier-study.md`.

The capture script has since been rewritten for the refinement journeys; this
manifest came from its first version at `c85d6e67`.
