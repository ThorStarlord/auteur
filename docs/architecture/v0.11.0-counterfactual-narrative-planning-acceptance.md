# Auteur v0.11.0 Acceptance Report — Counterfactual Narrative Planning

## Summary

v0.11.0 adds a deterministic **Counterfactual Narrative Planning** subsystem
that lets an author compare the projected downstream consequences of multiple
candidate decisions without mutating accepted, canonical, planning, decision,
impact, or review state.

It composes v0.10 project planning with an isolated scenario overlay model:
real state is captured in an immutable baseline, candidate-specific hypothetical
deltas are applied as an overlay, and existing impact and planning engines
operate on the overlaid state to produce projections.

### Architecture

```
src/auteur/simulation/
    __init__.py        — exports and public API
    models.py          — CounterfactualBaseline, CounterfactualScenario, ScenarioComparison,
                        ProjectedConsequence, confidence, classification, lifecycle
    baseline.py        — immutable capture of current project state
    overlay.py         — isolated candidate-specific hypothetical state delta
    projection.py      — candidate-specific impact and plan projection
    comparison.py      — semantic scenario comparison without automatic winner
    persistence.py     — immutable baselines, scenarios, projections, comparisons
    promotion.py       — safe delegation into Author Review Sessions
    service.py         — application-service boundary for CLI and workflow
    cli.py             — 10 subcommands with --project and --json support
```

## Limitations

1. No calendar scheduling or duration estimation
2. No automatic artistic winner selection
3. No story-quality scores or confidence percentages
4. No manuscript generation inside simulation
5. No reader-response or market-success prediction
6. No background distributed simulation workers
7. Review-session projection is structural only (no semantic review analysis)
8. Workflow integration is structural — no automatic simulation recommendations
9. Impact projection from `impact_preview()` depends on real decisions existing

## Deferred scope

- Automated artistic winner selection
- Story-quality scoring
- Fake confidence percentages
- Reader-response or market-success prediction
- Manuscript generation inside simulations
- Full repository cloning
- Git branches as scenario storage
- Acceptance from simulation
- Automatic review abortion or publishing
- GUI-first architecture or cloud collaboration
