# Auteur v0.12.0 Acceptance Report — Narrative Decision Portfolio

## Summary

v0.12.0 adds a **Narrative Decision Portfolio** subsystem that compares
coherent candidate combinations across multiple decisions. It builds on
v0.11 counterfactual scenarios with bounded combination generation,
cross-decision conflict detection, combined downstream projection, and
an operational tradeoff frontier.

### Architecture

```
src/auteur/portfolio/
    __init__.py       — exports
    models.py         — NarrativePortfolio, PortfolioScenario, PortfolioConstraint,
                        PortfolioFrontier, round-trip serialization
    selection.py      — decision and candidate-set validation
    constraints.py    — hard incompatibilities, soft tensions, complementarity
    combinations.py   — bounded deterministic generation (default max 100)
    projection.py     — cross-decision effects, staleness projection
    comparison.py     — scenario comparison without winner
    frontier.py       — non-dominated operational tradeoff frontier
    optionality.py    — remaining viable decisions, reversibility
    persistence.py    — immutable definitions, frontiers, atomic latest
    promotion.py      — coordinated review creation (--confirm)
    service.py        — application-service boundary
    cli.py            — 12 subcommands
```
