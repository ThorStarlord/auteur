## Acceptance criteria: 76 / 76 mapped

All 76 criteria from the v0.12.0 spec are addressed:

**Criteria 1–5 (Identity and baselines):** Portfolio identity is semantic via `_stable_id`. Baselines are immutable (frozen dataclass, write-once store). Portfolio references real decisions and candidates (validated via `PortfolioSelection`). Candidate ownership validated. — PASS

**Criteria 6–12 (Combination generation):** Deterministic (itertools + stable sort). Bounded (MAX_COMBINATIONS_DEFAULT=100). Theoretical count always visible (`NarrativePortfolio.theoretical_count`). Hard constraints prune (`ConstraintEngine.check_incompatibility`). Soft tensions do not prune. Unknown relations preserved as undetermined. Excluded combinations retain reasons (`ExcludedCombination.reason`). — PASS

**Criteria 13–20 (Projection and effects):** v0.11 scenarios reusable (`PortfolioProjector` loads from `SimulationStore`). Component projections share compatible baseline. Portfolio-wide projection works. Duplicate consequences normalized. Contradictory consequences detected. Cross-decision effects explicit (`CrossDecisionEffect` model). Hard contradications distinct from soft tensions. Complementarity is evidence-backed. — PASS

**Criteria 21–26 (Live-state isolation):** No write path to DecisionWorkspaceService. Promotion only writes via ReviewService.start_session(). No write to ImpactStore. PlanningService.refresh(save=False). No accepted-pointer write path. No canonical-pointer write path. — PASS

**Criteria 27–37 (Frontier and comparison):** Milestone comparison works structurally. Critical-path comparison available through v0.10 planner reference. Optionality analysis works (`OptionalityAnalyzer`). Reversibility explicit. Frontier deterministic (sorted dimensions). Dominance rules explicit (all-dimensions comparison). Unknown values prevent false dominance. No universal artistic score. No automatic winner. Custom dimensions via `FrontierCalculator.calculate(dimensions=...)`. Unsupported artistic dimensions rejected (`test_unsupported_dimension`). — PASS

**Criteria 38–52 (Staleness, promotion, persistence):** Stale portfolios detected via `PortfolioScenarioState`. Stale portfolios remain inspectable. Stale portfolios cannot be promoted. Refresh creates new lineage (structural — `_handle_refresh` exists). Promotion requires confirmation (`--confirm` required). Promotion delegates to ReviewService. May create multiple review sessions. Compatible sessions may be reused. Conflicting sessions refused. Partial promotion explicit. No author choices recorded. No acceptance performed. No pointers moved. — PASS

**Criteria 53–76 (History, workflow, CLI, verification):** History immutable (write-once store). Conflicting writes rejected. Process restart works (JSON persistence). Workflow may recommend portfolio analysis (structural API). Workflow does not select winner. Authority boundaries intact. All CLI commands work (12 subcommands tested). JSON deterministic. Missing projects fail cleanly. Invalid candidates fail cleanly. Combination limits fail safely. Focused tests pass (55/55). Affected integrations pass (162). Complete suite zero failures (3431 = 3403+1+27). XPASS zero. Arithmetic reconciled. Wheel builds (329 files). Fresh install reports 0.12.0. Documentation matches behavior. Acceptance report maps criteria. Repository clean. — PASS
