# Architectural Design Specification: Auteur v0.36 Golden-Path Gap Repairs

## 1. Problem Overview & Scope

The v0.36 dogfood review validated Auteur's core product promise (**CORE PROMISE VALIDATED WITH SPECIFIC GAPS**). Four concrete golden-path gaps were identified:

1. **`FORCED_GENRE_RECOMMENDATION`**: A non-erotic premise (Scenario B: sci-fi murder mystery on Titan) was recommended as `Erotic Psychological Drama` (`erotic_psychological_drama`) with 88% confidence because `erotic_fiction` is the only installed pack in v0.36.0. The system conflates profile ranking within a pack with pack domain applicability.
2. **`IDENTITY_RECOMMEND_REQUIRES_LLM_KEY`**: Running `auteur identity recommend` without a configured Anthropic/OpenAI API key fails after 4 hidden retry attempts with `Error: Failed to generate a valid StoryIdentity after maximum retries` instead of detecting missing credentials early and offering actionable setup guidance or `auteur identity init`.
3. **`RECOMMENDATION_ACCEPT_REQUIRES_EXISTING_IDENTITY_FILE`**: `auteur genre recommendation accept` raises `[PACK_NOT_FOUND]` if `story_identity.yaml` does not exist in the target project directory.
4. **`SUBGENRE_VALIDATION_UNKNOWN_WARNING_FOR_PACK_PROFILES`**: Validating an accepted `StoryIdentity` containing `subgenres: [erotic_psychological_drama]` triggers `[WARNING] identity.subgenre.unknown` because the subgenre modifier loader does not check installed Genre Pack profile IDs.

## 3. Detailed Technical Designs

### Repair 1: Pack Applicability & Abstention Engine

#### Architecture & Models (`src/auteur/genre_packs/models.py` & `recommendation.py`)
Introduce typed applicability status and separate pack applicability confidence from profile selection confidence:

```python
class PackApplicabilityStatus(str, Enum):
    APPLICABLE = "applicable"
    WEAK_FIT = "weak_fit"
    NOT_APPLICABLE = "not_applicable"
    INSUFFICIENT_EVIDENCE = "insufficient_evidence"

class PackApplicabilityEvaluation(BaseModel):
    pack_id: str
    version: str
    status: PackApplicabilityStatus
    applicability_score: float  # 0.0 to 1.0
    matched_signals: list[str] = Field(default_factory=list)
    missing_signals: list[str] = Field(default_factory=list)
    negated_signals: list[str] = Field(default_factory=list)
    explanation: str

class GenreRecommendationAdvisory(BaseModel):
    status: str = "no_applicable_pack"
    message: str
    evaluated_packs: list[PackApplicabilityEvaluation]
    recommended_next_actions: list[str]
    mutated_state: bool = False
```

#### Applicability Scoring Logic (`src/auteur/genre_packs/recommendation.py`)
1. **Domain Signal Audit**:
   - `erotic_fiction` required core signals: desire, intimacy, erotic, passion, sexual, romantic attraction, sensual, affair, lover, relationship boundary.
   - Negated / Exclusion signals: explicitly non-erotic context, pure mechanical mystery without desire, military sci-fi.
2. **Scoring Thresholds**:
   - `score >= 0.30`: `APPLICABLE` (Proceed to opinionated subgenre profile recommendation).
   - `0.10 <= score < 0.30`: `WEAK_FIT`.
   - `score < 0.10`: `NOT_APPLICABLE`.
3. **Abstention Contract**:
   - When no installed pack achieves `APPLICABLE` status, `recommend_genre_profile()` returns a `GenreRecommendationAdvisory` (or candidate with `status="no_applicable_pack"` and `recommendation_id=None`).
   - Human output explains: No strong pack match found, evaluated packs and evidence, zero state mutation occurred, and available next steps.
   - JSON output returns stable structure with `status: "no_applicable_pack"`.
   - No recommendation candidate artifact is written to disk during abstention.

### Repair 2: LLM Prerequisite Contract & `auteur identity init`

#### Prerequisite Detection (`src/auteur/cli_dispatch.py`)
Before initiating `auteur identity recommend`, check if required API keys are configured (`ANTHROPIC_API_KEY` or `OPENAI_API_KEY`).
If missing:
- Return a clear user-facing error message with zero stack trace.
- Show exact environment variable setup steps (`$env:ANTHROPIC_API_KEY = "sk-..."` / `export ANTHROPIC_API_KEY="..."`).
- Suggest the offline `auteur identity init` command.

#### Offline Command: `auteur identity init` (`src/auteur/cli_parser.py`, `cli_dispatch.py`, `cli_handlers.py`)
- Syntax: `auteur identity init [--output OUTPUT] [--premise PREMISE] [--title TITLE]`
- Creates an explicit, author-editable `story_identity.yaml` skeleton populated with available premise text and clean structural placeholders without claiming AI recommendation occurred.

---

### Repair 3: Recommendation-to-Identity Orchestration

#### Missing Identity Handling (`src/auteur/genre_packs/cli.py`)
When `auteur genre recommendation accept <rec_id> --project <path>` is executed:
- Check if `<path>/story_identity.yaml` exists.
- **If absent**:
  - Do NOT fabricate incomplete identity commitments (`want`, `conflict`, `core_answer`).
  - Stop execution safely with clear guidance:
    ```text
    No story_identity.yaml found in project directory.
    Your recommendation 'rec_123' remains saved in .auteur/genre_recommendations/.
    
    To proceed:
      1. Run 'auteur identity init --project <path> --premise "<text>"'
      2. Re-run 'auteur genre recommendation accept rec_123 --project <path> --confirm'
    ```
  - Zero files are mutated or corrupted.

---

### Repair 4: Pack Profile Recognition in Identity Validation

#### Subgenre Resolution (`src/auteur/identity.py`)
In `StoryIdentity.validate_identity()`:
- When checking `self.story_type.subgenres`:
  - First check if subgenre has a legacy `load_subgenre_modifier(sub)`.
  - If not found, check if `sub` matches `self.genre_profile.primary_profile_id` or is a valid subgenre profile ID in `get_pack_registry()`.
  - If valid pack profile, skip emitting `identity.subgenre.unknown`.
  - If subgenre is neither a legacy modifier nor a known pack profile ID, emit `identity.subgenre.unknown`.

## 4. Verification & Testing Strategy

1. **Unit & Integration Tests**:
   - `test_pack_applicability_erotic_fiction()`: verifies natural fit returns `APPLICABLE`.
   - `test_pack_applicability_sci_fi_mystery()`: verifies Titan murder mystery premise returns `NOT_APPLICABLE`.
   - `test_pack_applicability_abstention_output()`: verifies human and JSON outputs for `no_applicable_pack`.
   - `test_identity_validate_recognizes_pack_profiles()`: verifies `erotic_psychological_drama` validates cleanly.
   - `test_identity_recommend_missing_api_key()`: verifies clear prerequisite error output.
   - `test_identity_init_creates_editable_skeleton()`: verifies `auteur identity init`.
   - `test_genre_recommendation_accept_missing_identity_guidance()`: verifies safe prerequisite warning when `story_identity.yaml` is missing.

2. **Re-Run Dogfood Scenarios**:
   - Scenario A (Natural Fit): full golden-path execution.
   - Scenario B (Ambiguous Fit): verify clean abstention advice without forced recommendation.
