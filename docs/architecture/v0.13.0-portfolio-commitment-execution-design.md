# Auteur v0.13.0 — Portfolio Commitment and Coordinated Execution

## Overview

v0.13.0 adds a **Portfolio Commitment and Coordinated Execution** subsystem
that lets an author select one portfolio scenario as an intended creative
direction and carry it through normal review, analysis, and acceptance
workflows without treating commitment as blanket authorization.

## Architecture

```
src/auteur/commitment/
    __init__.py        — exports
    models.py          — commitment, execution plan, divergence contracts
    planner.py         — convert selected portfolio into execution plan
    execution.py       — delegate safe steps, create/reuse reviews
    progress.py        — per-assignment and aggregate progress
    divergence.py      — compare committed direction against live state
    persistence.py     — immutable commitments, plans, events
    service.py         — application-service boundary
    cli.py             — argument parsing and rendering
```

## Key decisions

- Commitment uses `auteur commit` (avoids Git `commit` ambiguity via context)
- Commitment identity: `stable_id(project, portfolio_scenario, assignments_hash, assumptions_hash)`
- No acceptance during commitment creation or execution
- Execution plans delegate to existing ReviewService, PlanningService
- Divergence is detected by comparing committed state against live state
- Supersession creates new immutable commitment; old remains inspectable

## Commit lifecycle

CREATED → PLANNED → EXECUTING → (DIVERGED ⇄ RECONCILING) → COMPLETED/SUPERSEDED/ABORTED

## CLI surface

```
auteur commit create      — create commitment from portfolio scenario (--confirm)
auteur commit status      — show aggregate progress
auteur commit inspect     — inspect commitment details
auteur commit plan        — generate execution plan
auteur commit execute     — execute safe steps
auteur commit check       — scan for divergence
auteur commit reconcile   — produce reconciliation plan
auteur commit supersede   — supersede commitment (--confirm)
auteur commit history     — show event history
auteur commit list        — list commitments
auteur commit abort       — abort commitment
```

## Deferred scope

- Batch acceptance, blanket authority delegation
- Automatic artistic choice or manuscript generation
- Team assignments, calendar scheduling, cloud sync
