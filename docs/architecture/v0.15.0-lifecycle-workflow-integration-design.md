# Auteur v0.15.0 — Lifecycle-Workflow Integration

## Overview

v0.15.0 integrates the Decision Lifecycle (v0.14.0) into the existing
Guided Author Workflow (v0.4.0). After this release, `auteur workflow`
commands incorporate lifecycle data: open decisions, simulation gaps,
portfolio assignments, commitment state, and divergence warnings.

This is a pure composition layer — no new state, no new persistence.
Lifecycle data is probed from existing services and formatted alongside
workflow stage output.

## Design

### WorkflowState extension

Add `lifecycle: dict[str, Any]` field to `WorkflowState` dataclass.
Serialized in `to_dict()` for JSON consumers.

```python
lifecycle = {
    "total_decisions": 3,
    "by_stage": {"open": 1, "simulated": 1, "committed": 1},
    "simulated": 1,
    "in_portfolio": 1,
    "under_review": 0,
    "accepted": 0,
    "committed": 1,
    "diverged": 0,
    "with_gaps": 2,
}
```

### WorkflowEngine lifecycle probe

Follows the existing `_decision_service` pattern:

```python
class WorkflowEngine:
    def __init__(self, project_root, decision_service=None, lifecycle_service=None):
        self._lifecycle_service = lifecycle_service

    def analyze(self) -> WorkflowState:
        # ... existing stage/blocker/action logic ...
        lifecycle = self._probe_lifecycle()
        return WorkflowState(..., lifecycle=lifecycle)
```

### Summary string enhancement

`_build_summary()` appends lifecycle counts when data exists:

```
Current stage: realization
Decisions: 3 open, 1 simulated, 1 committed, 0 diverged
```

### Lifecycle-gap actions in workflow next

New `recommend_lifecycle_actions()` in rules.py generates targeted
actions for decisions with lifecycle gaps:

| Gap | Action | Authority |
|-----|--------|-----------|
| Decision open, not simulated | `auteur simulate create ...` | DERIVED_ARTIFACT |
| Simulated, not in portfolio | `auteur portfolio add ...` | DERIVED_ARTIFACT |
| Portfolio, not promoted | `auteur portfolio promote ...` | CANDIDATE_GENERATION |
| Under review, acceptance ready | `auteur decision prepare-acceptance ...` | READ_ONLY |
| Diverged | `auteur commit check ...` | READ_ONLY |

These are appended to the existing `recommend_actions()` output when
lifecycle data is available and gaps exist.

### CLI output

`auteur workflow status` gains a Lifecycle section when decisions exist:

```
Lifecycle:
  Decisions:       3 total
  Open:            1
  Simulated:       1
  Portfolio:       1
  Under review:    0
  Accepted:        0
  Committed:       1
  Diverged:        0
  With gaps:       2
```

## Key decisions

- Follow existing `_decision_service` pattern for `_lifecycle_service`
- No new model types — reuse existing WorkflowBlocker, WorkflowAction
- Lifecycle section only shown when decisions exist (nonzero total)
- Lifecycle actions ranked after decision actions, before stage labels
- All probes are try/except — missing lifecycle service degrades gracefully

## Deferred scope

- Active lifecycle change alerts in workflow next
- Visualization/graph of lifecycle in workflow explain
- Team lifecycle views integrated with workflow
