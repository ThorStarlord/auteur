# Auteur v0.18.0 — Author Notification

## Overview

Add `auteur notify` — proactive scanning for events that need author attention.

## Interface

```
auteur notify          — scan and show all findings
auteur notify --json   — structured JSON output
```

## Scan dimensions (all read-only)

- **Divergence** — committed candidate ≠ current candidate (commitment subsystem)
- **Stale commitments** — commitment state is stale or diverged
- **Review readiness** — sessions ready for acceptance preparation
- **Lifecycle gaps** — decisions not simulated, not portfolio'd, not promoted
- **Execution failures** — commitment execution steps failed

## Architecture

```
src/auteur/notify/
    __init__.py   — exports
    models.py     — NotificationFinding, NotificationSeverity, NotificationType
    scanner.py    — scans all subsystems, produces findings
    service.py    — application boundary
    cli.py        — CLI command
```
