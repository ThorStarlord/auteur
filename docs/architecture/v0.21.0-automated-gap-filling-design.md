# Auteur v0.21.0 — Automated Gap Filling

Fill lifecycle gaps automatically: simulate un-simulated decisions,
create portfolios for simulated decisions, promote portfolio scenarios.

## CLI

```
auteur lifecycle fill [--gap simulate|portfolio|promote] [--confirm]
  Without --gap: show all fillable gaps
  With --gap: fill only that gap type
  --confirm required to execute
```

## Behavior

- Scans lifecycle via existing integrator
- For each fillable gap, routes to appropriate subsystem
- Requires --confirm for each action
- Reports results per action
