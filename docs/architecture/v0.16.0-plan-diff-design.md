# Auteur v0.16.0 — Plan-diff

## Overview

Add `auteur plan diff` command to compare two plan snapshots and show what changed.

## Interface

```
auteur plan diff <plan_id1> [plan_id2]
  If plan_id2 is omitted, diff against latest plan.
  --json  structured diff output
```

## Diff dimensions

- **Nodes** — added/removed/changed (by node_id)
- **Edges** — added/removed  
- **Milestones** — state changes (not_started→completed, stale, etc.)
- **Critical paths** — added/removed/changed
- **Blockers** — resolution (blocker removed) or new blockers
- **Actions** — added/removed

## Implementation

- Add `PlanStore.load_snapshot(plan_id)` + `load_latest()` 
- New `PlanDiffer` class in `src/auteur/planning/differ.py`
- CLI handler in `planning/cli.py`
