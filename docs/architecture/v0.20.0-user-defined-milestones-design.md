# Auteur v0.20.0 — User-defined Milestones

Authors define custom milestones alongside system-derived ones.

## CLI

```
auteur plan milestones --add "Title" [--scope chapter] [--description "..."] [--project .]
auteur plan milestones --list [--json]
auteur plan milestones --remove <milestone_id>
```

## Storage

User milestones stored in `.auteur/planning/user_milestones.yaml`.

## Integration

- `auteur plan milestones` merges system + user milestones in output
- User milestones get `milestone_id: user-<hash>`, state tracked separately
