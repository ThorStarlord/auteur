# Auteur v0.12.0 — Narrative Decision Portfolio

## Overview

v0.12.0 adds a **Narrative Decision Portfolio** subsystem that compares
coherent combinations of candidates across multiple decisions. It builds
on v0.11 counterfactual scenarios to generate bounded candidate portfolios,
detect cross-decision conflicts, project combined downstream effects, and
present an operational tradeoff frontier.

## Architecture

```
src/auteur/portfolio/
    __init__.py       — exports
    models.py         — portfolio, constraint, combination, frontier contracts
    selection.py      — decision and candidate-set validation
    constraints.py    — hard incompatibilities, soft tensions, complementarities
    combinations.py   — bounded deterministic portfolio generation
    projection.py     — portfolio-wide impact and planning projection
    comparison.py     — semantic portfolio comparison
    frontier.py       — non-dominated operational tradeoff frontier
    optionality.py    — remaining viable decisions and reversibility
    persistence.py    — immutable definitions, projections, frontiers
    promotion.py      — coordinated promotion into Author Review Sessions
    service.py        — application-service boundary
    cli.py            — presentation and argument parsing
```

## Key design decisions

- Reuses v0.11 scenario projection — portfolio projection combines component scenarios
- Combination generation is bounded with configurable limits
- Constraints are evidence-classified (KNOWN/DERIVED/INFERRED/UNKNOWN)
- Hard constraints prune; soft tensions remain visible
- Frontier is operational only (blockers, uncertainty, optionality — never artistic quality)
- Dominance rules: non-dominated on every operational dimension
- No universal winner score or automatic artistic ranking
- Promotion creates coordinated review sessions through existing Review Service

## Portfolio identity

`stable_id(project, baseline_id, sorted_decisions, sorted_candidates, normalized_constraints, normalized_assumptions, policy)`

## Default limits

- max_decisions: 5
- max_candidates_per_decision: 4
- max_combinations: 100

## Deferred scope

- Unbounded exhaustive search, genetic algorithms, reinforcement learning
- Automatic artistic optimization, story-quality scoring
- Reader-response or market-success prediction
- Manuscript generation or automatic acceptance
- Cloud collaboration or distributed workers
