# Auteur v0.22.0 — Chapter Structure Propose

Add `auteur structure propose` — generate chapter-level structural
proposals from project state.

## CLI

```
auteur structure propose [--project .] [--json]
  Lists diagnostic-based proposals for chapter structure.

auteur structure propose --apply <proposal_id> [--project .]
  Apply a specific proposal.

auteur structure propose --list [--json]
  List all pending proposals.
```

## Implementation

- Reads diagnostics from `.auteur/structure/diagnostics/`
- Uses existing StructureProposal model and proposal infrastructure
- CLI integrated into existing structure command group
