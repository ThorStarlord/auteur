# Auteur v0.17.0 — Commitment Execution Workflow

## Overview

Integrate commitment execution progress into the Guided Author Workflow.
After this release, `auteur workflow status` shows commitment execution
progress, and `auteur workflow next` routes the author to commitment gaps.

## Integration

- WorkflowEngine accepts optional commitment_service
- Probes: commitment count, state, execution plan progress, divergence
- Summary appends commitment info
- CLI formatter shows commitment section
- recommend_actions adds commitment gap actions
