# Auteur v0.19.0 — Batch Acceptance

Accept all committed decisions in one command. Routes each through
existing review/acceptance services.

## CLI

```
auteur commit accept <commitment_id> [--assignment dec_id] [--confirm]
  Without --assignment: accepts ALL decisions in the commitment
  With --assignment: accepts only that decision
  --confirm required
  --json for structured results
```

## Behavior

Per assignment:
1. Find review session for that decision_id
2. Call prepare_acceptance() — validates readiness
3. Call accept() with as_committed=True
4. Record result: accepted/skipped/failed

Skips already-accepted decisions.
Reports per-assignment results with diagnostic messages.
