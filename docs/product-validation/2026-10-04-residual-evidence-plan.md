already answer.

walkthrough already supplied claim-appropriate experiential evidence and exposed

mechanically exercised. That evidence selected the bounded Beginner

cases. Those do not substitute for the current B/C/D ergonomics comparison, but
they are genuine prior human/owner judgment and should not be erased from the
evidence history.

Therefore #305 is a **current-version contradiction check**, not a reset to
zero human validation.

## 2. #305 — minimal real-author evidence

### Default comparison

Use only current/relevant conditions by default:

- **B — compressed Shape-first Auteur**
- **C — Quick Draft / Write-first Auteur**
- **D — Markdown + capable general-purpose LLM**

The historical ~22-interaction pre-compression flow is now an **optional
diagnostic control**, not a required participant condition.

Use it only if current evidence is ambiguous about whether compression itself
caused a regression.

### Questions that still require a person

Observe only what repository simulation cannot establish:

1. Which current entry tempo does the writer naturally want for their current
   creative state?
2. Does compressed Shape-first feel like guidance or approval ceremony?
3. Does Quick Draft preserve a sense of ownership?
4. Does `What did we discover?` feel like insight or noise when limited to
   consequence-bearing changes?
5. Does **Keep draft & update story** feel like creative help or bookkeeping?
6. Are deeper/customization controls discoverable when wanted?
7. Is the story-language mental model understandable without teaching internal
   semantic layers?
8. Does continuity assistance create enough **felt** value over Markdown + a
   capable general-purpose LLM?
9. Would the writer continue the story in Auteur?

### Do not spend participant time re-proving

- designed interaction counts;
- provisional vs accepted authority;
- exact-draft freshness;
- unknown-field persistence;
- no-silent-canon behavior;
- existence of discovery / divergence / revise choices;
- mechanical preservation of prose;
- mechanical lowest-sufficient-owner routing.

Those are preconditions, not participant questions.

### Minimum useful result

One serious participant pass can produce a **directional product signal**, but
must not be generalized to writer populations.

Additional participants become warranted only if the first pass reveals a
decision-changing contradiction or if a population-level claim is desired.

## 3. #310 — minimal live-provider evidence

Keep all four scenarios because provider behavior is now the variable:

1. named-character mystery;
2. character-driven contemporary;
3. speculative hook;
4. intentionally vague premise.

For each run record:

- configured provider/model;
- observed latency;
- exact premise;
- exact first-scene intent;
- exact generated prose;
- output size;
- provisional scaffold;
- whether provider output follows the requested scene intent;
- whether output is scene-sized rather than story-summary-sized;
- whether generic provisional defaults visibly leak into prose;
- whether the vague case receives unwanted commitment pressure.

For one run, perform the existing Sister Beatrice + convent edit and verify the
generated-prose path still reaches the established discovery/handoff mechanics.

### Do not claim from #310

- writer preference;
- ownership;
- joy;
- lower cognitive load;
- desire to continue;
- felt superiority over Markdown/LLM.

### Execution boundary

A real provider run requires an environment with configured credentials and may
consume external provider quota/cost. Repository preparation can be completed
remotely; the live call itself must occur only in an authorized configured
environment.
