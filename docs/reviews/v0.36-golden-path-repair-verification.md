### Additional Repair Over Previous Candidate

`413640c` adds one further defect correction over `a769fb0`:

```
fix(identity-init): normalize genre casing before enum validation

Genre values like 'Sci-Fi' were being passed as 'Sci_Fi' (after
replace but before lower) and failing Pydantic enum validation.
Apply .lower() before .replace('-', '_') and validate against
Genre enum, falling back to Genre.OTHER for unknown values.
```

This defect was discovered during the installed-wheel verification: passing
`--genre "Sci-Fi"` via the CLI caused a `ValidationError`. The fix is
defensive — it does not alter recommendation heuristics.
