# Auteur 1.0.0 — Bounded local-first release

Auteur 1.0.0 provides a local-first, single-author narrative engineering
workflow from premise and accepted Story Identity through whole-story
Structure, bounded Chapter/Scene Realization and Expression, deterministic
diagnostics, explicit proposals and decisions, Book reconciliation, and
HTML/EPUB publication.

The release deliberately does not promise collaboration, cloud services,
native GUI workflows, markerless manuscript mapping, paragraph movement,
Scene merge/split, grouped dependent decisions, or broad long-horizon Series
intelligence. Those capabilities remain deferred or experimental as defined
in [the 1.0 scope](../1.0-scope.md).

Release qualification must be recorded from the exact frozen candidate SHA in
[the qualification record](../engineering/v1.0-qualification-record.md).
