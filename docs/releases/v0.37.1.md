# Auteur v0.37.1 — Post-Release Reliability and Authority Hardening

## Release Classification
Patch release containing bounded correctness, authority-safety, and compatibility improvements after v0.37.0.

## Overview
Auteur v0.37.1 addresses three bounded findings from the v0.37.0 post-release dogfood review: explicit negation false positives in Genre Pack applicability, missing confirmation enforcement on authoritative recommendation mutations, and a Pydantic V2 deprecation warning in scene-state models.

## Fixed

1. **Negation-Aware Applicability (F-01)**
   - Explicit domain negation such as `"This is not an erotic story"` no longer contributes positive Erotic Fiction applicability evidence.
   - Signal-local negation filters negated desire, attraction, or intimacy signals from positive evidence.
   - Mention-without-embodiment cases (e.g., `"a scholar studies erotic literature"`) abstain reliably.
   - Determined heuristic uses three-layer phrase-based detection: global domain negation, local signal negation, and signal-local substring filtering.

2. **Override Authority Confirmation (F-02)**
   - `auteur genre recommendation override` now requires explicit `--confirm` flag before mutating `story_identity.yaml`.
   - `auteur genre recommendation accept` confirmation remains explicit.
   - Unconfirmed authoritative mutations leave StoryIdentity byte-for-byte unchanged.
   - `--confirm` is required for both human and JSON output paths.

3. **Pydantic V2 Migration (F-03)**
   - Scene-state models (`KnowledgeFact`, `EmotionalState`, `EntryState`, `ExitState`) migrated from class-based `class Config:` to `model_config = ConfigDict(...)`.
   - Import-time `PydanticDeprecatedSince20` warnings eliminated.
   - Field names, serialization, and validation semantics unchanged.

## Preserved
- Legitimate in-domain premises remain applicable.
- Character denial inside an otherwise erotic story does not automatically cause abstention.
- Titan mystery abstention remains intact.
- Recommendation candidates remain inspectable.
- Override rationale persists across sessions.
- StoryIdentity remains the Layer 1 authority.
- Public serialization fields remain compatible.

## Known Limitations
- Applicability evaluation remains deterministic and heuristic; it does not claim robust semantic classification.
- The marine-biologist natural-fit premise scores approximately 0.40 against the 0.30 threshold.
- Complex nested negation and pronoun coreference are not semantically resolved.
- Phrase coverage is curated rather than unrestricted NLP.

## Compatibility Note
`auteur genre recommendation override` now requires `--confirm`. Scripts that previously invoked override without `--confirm` will fail safely with no mutation and must be updated.
