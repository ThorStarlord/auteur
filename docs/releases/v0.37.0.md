# Auteur v0.37.0 — Golden-Path Reliability and Honest Abstention

## Release Classification
Product-capability and workflow release built on v0.36.0.

## Overview
Auteur v0.37.0 repairs critical golden-path usability and authority gaps identified during real-world dogfood reviews of v0.36.0. It ensures Auteur evaluates pack applicability before profile ranking, refrains from forcing out-of-domain Genre Packs onto author premises, introduces offline skeleton identity initialization (`auteur identity init`), provides explicit `confidence: null` semantics for un-evaluated skeletons, and offers guidance when LLM provider API keys are missing.

## Key Features and Fixes

1. **Pack Applicability & Honest Abstention**
   - Pack applicability evaluation (`evaluate_pack_applicability`) now precedes profile ranking.
   - When no installed Genre Pack matches an author's premise, Auteur returns a structured `GenreRecommendationAdvisory` (`status: "no_applicable_pack"`) with score and matched/missing signals instead of forcing low-relevance recommendations.
   - Zero state mutation occurs when abstaining.

2. **`auteur identity init` & Offline Skeleton Semantics**
   - Authors can initialize an author-editable Layer 1 `story_identity.yaml` skeleton without invoking LLM providers or requiring API keys.
   - Initialized skeletons explicitly set `confidence: null` (`confidence=None`) to reflect an un-evaluated offline template rather than implying 50% confidence.
   - Placeholders are clearly marked, and zero `GenreProfileCommitment` objects are populated until explicit acceptance occurs.

3. **Provider Key Guidance & Error Recovery**
   - Running AI-powered recommendations (`auteur identity recommend`) without `ANTHROPIC_API_KEY` or `OPENAI_API_KEY` fails immediately before network calls, giving concise setup instructions and pointing to `auteur identity init`.
   - Accepting a saved recommendation when `story_identity.yaml` is absent preserves the recommendation candidate in `.auteur/genre_recommendations/` and provides clear recovery commands.

4. **Built-in Pack Profile Validation**
   - Subgenre validation recognizes built-in pack profile IDs, eliminating false-positive unknown-subgenre warnings during `auteur identity validate`.

5. **Windows Console Output Compatibility**
   - All CLI output formatters replace non-ASCII arrows and symbols (`->`, `...`) with ASCII equivalents, preventing `UnicodeEncodeError` exceptions on Windows consoles (`cp1252`).

## Architectural Scope & Limitations
- Applicability checks use deterministic lexical and n-gram signal matching against pack contracts.
- Auteur preserves author authority: Auteur advises and evaluates, but does not overwrite author intent or silently mutate blueprints without explicit author acceptance.
