**That inference is contradicted by its own evidence.** Case B's ambiguous clause — "accurate to the ground as surveyed" — was supplied in the author brief. The investigation therefore never established a source-origin distinction between author-supplied and agent-invented premises.

## 2. Matched diagnostic

Two fresh briefs, matched on genre (nine-Book signal-keeper series), length, commitment count, stakes, intended reader experience, task wording and model. Only the criterion's **location** differs.

| | Criterion | Location |
|---|---|---|
| Task A | "a warning counts as *heard* only if it changes what someone does" | author's governing artistic criterion |
| Task B | "a warning counts as *heard* only when the receiving station repeats it back" | rule inside the fictional world |

Both hinge on what "heard" means. Neither agent was told a term was ambiguous, and neither knew the other task existed.

### Results

**Task A (2,337 words).** It recognised the criterion as the engine — "It operationalises the author's criterion… stops being a theme and becomes a rule" — and produced a mechanism with grades, wager lines, and an archive. It **resolved** the ambiguity silently by adding a recording condition: "A warning is heard when a person who did not send it changes what they do, **and the change is entered at the station that received it**." It never flagged that it had chosen.

**Task B (3,916 words).** It recognised the clause as the engine — "The charter's sentence is not a courtesy. It is a transfer of custody" — and built a distributed-custody mechanism where "the cost of a warning is never paid where the warning is made." It also never flagged ambiguity, and read "repeats it back" as assumption-of-custody, which is a third reading neither of the two I had predicted.

### Disposition: **Outcome B — both tasks succeed; conceptual location is not reproduced**

| Dimension | Task A | Task B |
|---|---|---|
| Recognised the premise as load-bearing | Yes | Yes |
| Explicitly identified ambiguity | **No** | **No** |
| Silently adopted a reading | Yes | Yes |
| Traced consequences of that reading | Yes | Yes |
| Committed to a direction | Yes | Yes |
| Manufactured uncertainty | No | No |
| Efficient | Yes | Yes |

Neither response manufactured ambiguity, and neither asked the author to resolve anything. Both did what a competent architect should do: pick a reading and build.

## 3. What this changes

The failure in VLS-01 is **not** failure to notice ambiguity, and the matched pair shows in-world ambiguity is not noticed either. Both agents silently adopted a reading; both did it competently.

So the differentiator is not location, and probably not recognition. The surviving candidates are salience/framing (H2), Studio's construction-attention burden (H3), ordinary variation (H4), and — new, from this pair — **H5: resolving ambiguity productively rather than flagging it is normal and usually correct.**

If H5 is the better explanation, then VLS-01's defect is narrower than "didn't notice": it is that a silently chosen reading was then used to support a **distant necessity** the author never established. That is traceability of a chosen reading to a far consequence, not activation of scrutiny.

## 4. What the evidence does not support

- A conceptual-location mechanism.
- The source-origin distinction previously claimed.
- Any claim that the agent is unreliable at causal-premise reasoning — four uncoached successes now, zero failures, across two experiments.
- Any claim that an intervention would help. **No intervention was tested.** The prior record's candidate prompt change is untested and its rationale is now weakened.

## 5. Uncontrolled differences in the pair

Task B's output was 68% longer and its criterion is a procedural rule rather than an evaluative one, which may make it more naturally mechanism-generating. Both briefs were authored by me and were compact; neither resembles Studio's full construction request. One run each — no reliability claim.

## 6. Narrowest warranted next responsibility

**Not** activation of scrutiny, and **not** a prompt intervention.

The one thing the evidence points at is narrower: does a silently chosen reading get **carried to a distant consequence as if it were established**? That is testable in a compact task — build a short architecture where one reading must be adopted, then ask what happens 20 Books later — without Studio, without 100 Books, and without schema changes.

**Not implemented.** No production prompt, schema, ontology or canonical state was modified.
